# Pranav Patel — Portfolio

My personal portfolio: case studies of backend, AI/LLM, and integration work, with an interactive system map and architecture diagrams.

**Live:** https://pranav245.github.io/portfolio/

Built with plain HTML, CSS, and JavaScript. No framework, no build step.

## Run locally

```
python3 -m http.server 8000
```

Then open http://localhost:8000.
